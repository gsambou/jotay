# Runbooks terrain

Procédures opérationnelles (FR) : provisionnement du parc, ouverture/clôture de session
caissier, opposition et réémission, clôture d'événement, gestion d'un écart de
réconciliation. À rédiger au fil de la Phase 0 — une feature qui touche le terrain
n'est PAS terminée sans son runbook (Definition of Done, SPEC chap. 14.5).
